# Garissa Digital Academy

## Project Description
Garissa Digital Academy is a school website developed as a practical web design project. The website provides information about the institution, its educational services and contact information.

## Technologies Used
- HTML5
- CSS3

## Website Pages
1. Home – Introduction to the school.
2. Services – List of educational services offered.
3. Contact – Contact information and contact form.

## Project Structure

```text
garissa-digital-academy/

```

## Features
- Simple navigation menu.
- Responsive CSS styling.
- School images.
- Numbered services list.
- Contact information.
- Contact form.
